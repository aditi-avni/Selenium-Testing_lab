# Assignment 9: Selenium Testing Tool

## Aim
To perform automated login testing on a web application using Selenium WebDriver and Java.

## Description
This assignment demonstrates the use of Selenium WebDriver to automate browser actions and test login functionality on the SauceDemo website. It includes testing with valid and invalid login credentials to verify successful login and the display of appropriate error messages.

## Technologies Used
- Java
- Selenium WebDriver
- Maven
- Google Chrome
- SauceDemo website

## Test Cases
1. **Valid Login:** Verify that the user can log in using valid credentials.
2. **Invalid Login:** Verify that an appropriate error message is displayed when incorrect credentials are entered.

## How to Run
1. Ensure Java, Maven, and Google Chrome are installed.
2. Open the project folder in VS Code.
3. Run `LoginTest.java` to test valid login credentials.
4. Run `LoginFailureTest.java` to test invalid login credentials.
5. Check the console output to view the test results.

## Result
Both login test cases were executed successfully. The valid login test verified successful navigation to the inventory page, while the invalid login test verified that an appropriate error message was displayed.
